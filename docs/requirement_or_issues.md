# 新的需求以及改動

## 数据库更新
1. 更新“会员信息”表，当前会员信息表有：佛光會員卡號，姓名 (繁)，姓名 (簡)，所屬分區，手機，投票狀態，投票時間這些字段
需要新增幾個字段：佛光會員卡號，姓名 (繁)，姓名 (簡)，givenname, surname，性別，所屬分會，手機號，Email，地址，投票狀態，投票時間
2. 更新“候選人信息”表，当前候選人信息表有：姓名，分區，職位，競選宣言，已任屆數，目前票數，操作
更新之後的字段為：佛光會員卡號，姓名 (繁)，姓名 (簡)，givenname, surname，性別，所屬分會，照片，個人介紹，手機號，Email，地址，學歷，職業，是否皈依，皈依師長，受戒狀態，義工組別
3. 關於中文姓名繁體和簡體部分的邏輯：中文姓名更新的時候，同步更新會員的簡體和繁體姓名；姓名驗證的時候，繁體中文、簡體中文、英文，有一個匹配就可以；投票頁面和後臺管理，顯示姓名的時候，根據當前用戶的偏好語言，選擇一種中文姓名顯示即可。
