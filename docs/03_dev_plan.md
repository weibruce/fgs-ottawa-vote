## 4. 依賴與風險

### 4.1 外部依賴

| 依賴 | 說明 | 風險 | 緩解 |
|------|------|------|------|
| 域名 + 證書 | HTTPS | 需要域名 + ICP 備案（國內雲） | 提前準備；Let's Encrypt 免費證書 |
| 伺服器 | 4C8G 雲伺服器 | 採購/配置 | 提前購買 |
| 會員名單 | 後臺匯入（會員號、姓名） | 名單不準確/遺漏 | 投票前由會務組核對；支持匯入前修改 |

> **零外部服務依賴**：身份確認只用佛光會員號（後臺匯入），不用簡訊、不用微信 OAuth。省掉外部服務認證、金鑰管理和額外成本。

### 4.2 技術風險

| 風險 | 機率 | 影響 | 緩解 |
|------|------|------|------|
| 微信內建瀏覽器相容問題 | 中 | 投票頁面顯示異常 | Day 5 開始真機測試（iOS + Android）；Tailwind 相容性 |
| 現場 Wi-Fi 不穩定 | 中 | 投票提交失敗 | 前端重試 + 後端冪等；4G 熱點備用 |
| 平票處理 | 低 | 選舉結果不明確 | 投票前由管理員確定規則（加賽/抽籤）；系統確認計票時偵測平票並提示 |
| 開放問題未確認 | 中 | 需求變動返工 | 平票規則、每人票數、第二輪名單、部署環境等（需求第 10 章）應在 Day 1-2 前確認 |

### 6.4 壓測（Locust）

```python
# loadtest.py
from locust import HttpUser, task, between

class Voter(HttpUser):
    wait_time = between(1, 3)
    
    @task
    def view_results(self):
        self.client.get("/api/votes/results?round_id=1")

class VoteSubmitter(HttpUser):
    wait_time = between(10, 30)
    
    @task
    def submit_vote(self):
        # 模擬投票提交
        self.client.post("/api/votes/submit", json={
            "voter_token": "test_token",
            "round_id": 1,
            "candidate_ids": [1, 2]
        })
```

**目標**（對齊需求 4.1 效能指標）：
- 150 併發查詢使用者 → P99 < 50ms
- 100 併發提交（峰值 30% 同時投）→ P99 < 200ms
- 持續 10 分鐘，無錯誤
